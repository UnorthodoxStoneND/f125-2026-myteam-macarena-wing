# My Team Macarena Wing [Swofty Add-On]

Red Bull-style reverse 160-degree rear-wing animation for 2026 My Team cars in F1 25. Version **1.0.0-test.1**, by **UnorthodoxStoneNDmodding**.

## Features

- Adjustable visual wing travel from **0 to 500 ms**, in 50 ms steps; default **250 ms**.
- Change the launching profile's slider during play, normally within 250 ms. Zero disables added smoothing.
- Applies to the five 2026 My Team engine variants while retaining existing car performance and liveries.

Uses Swofty Launcher’s managed rear-wing render binding.

## Install

Download the ZIP from this repository's Releases page, install it in Swofty and enable **My Team Macarena Wing - Red Bull Style**.

## Supported platforms

Windows x64, Steam F1 25 build **26566308**, the official 2026 content and Swofty Launcher **1.10.30 or later** retaining the required APIs. The DLL checks the exact game executable and instructions. Other builds and EA copies are not supported.
