# Installation

Download the ZIP from this repository's Releases page and drop it onto Swofty Launcher. Enable **My Team Macarena Wing - Red Bull Style** and restart the game once to load its DLL. Keep your existing livery and performance mods enabled.

The current ID is `unorthodoxstonendmodding.myteam-macarena-wing`. If upgrading from the earlier `walker-racing.myteam-macarena-wing` build, disable/remove that entry first. Do not run both. The corrected ID installs separately, so choose your preferred slider value again.

**Visual wing travel (ms)** ranges from 0 to 500 in steps of 50, default 250. Higher is slower. Zero follows the game's render fraction without added smoothing. Changes to the launching profile's slider apply during play, normally within 250 ms. Another profile's slider does not control the running session. Reset to defaults selects 250 ms.

If a slider shows repeated 250 values beyond 500 after an update, completely exit and reopen Swofty Launcher to clear its cached control. This refresh is separate from the mod's live setting updates.

Disable the mod and launch again to remove its changes. No new career or save edit is required.
